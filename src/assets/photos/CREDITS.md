# Photo credits

Every photograph on the site is a real photo from [Unsplash](https://unsplash.com), uploaded between 2015 and 2021
(before AI image generators existed). Unsplash's licence allows free commercial use without attribution; the
credits are listed here as a courtesy and so each image can be traced or replaced.

Files in this folder are picked up automatically by name (see `src/data/photos.js`). To swap a photo, replace the
file with another `.webp`/`.jpg`/`.png` of the same name.
